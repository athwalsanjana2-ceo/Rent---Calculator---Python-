# Rent Calculator in Python

A simple mini python project to split hostel/flat expenses between roommates.

## How it works?
Takes 5 inputs:
- Total Rent
- Total Food ordered
- Electricity Units Spent
- Charge per Unit
- Number of Persons

Formula: `(rent + food + (units * charge_per_unit)) / persons`

## How to Run
python rent_calculator.py

## Example Output
Enter your hostel/flat rent = 3000
Enter the amount of food ordered = 1500
Each person will pay = 6125.00
